## 当前结论

最近一轮重点目标是修复旧人体检测模型容易把“学生识别成老师”的问题，尤其是学生视角下前排/讲台附近学生被判成老师，以及老师视角下学生上台展示场景的角色边界。

当前候选模型：`human_detection_18`

当前代码状态：

- 业务 x86 模型入口：`AlgorithmUtils/app/model_zoo/human_detection.py`
- 当前 x86 `model_name`：`human_detection_18`
- 旧 Triton 算法：`AlgorithmUtils/models/triton/human_detection`，加载 `human_detection_16_dynamic.onnx`
- 新 Triton 算法：`AlgorithmUtils/models/triton/human_detection_18`，加载 `human_detection_18_dynamic.onnx`
- 开发 Triton 配置：`AlgorithmUtils/deploy/开发机Triton.yaml` 已加载 `human_detection_18`
- 旧模型和新模型都保留在 Triton 目录中，可以继续并行对比

总体判断：

- 实验18确实改善了主要痛点方向：`student -> teacher` 从 `43` 降到 `30`，下降约 `30.2%`。
- 但实验18不是全面胜出：`teacher -> student` 从 `4` 增到 `15`，student 漏检和 student 多检也变多。
- 业务单测上，实验18人数统计 MAE 更好，但站立识别略差，总通过数比旧模型少 2 个。
- 因此实验18适合作为当前候选和并行对比模型；如果要作为线上稳定替换，还需要继续压住 `teacher -> student` 回归和站立识别退化。

## 推荐训练配置

当前训练入口：

`/home/yujiannan/Projects/ultralytics/scripts/train_human_detection.py`

实验18的关键配置：

```python
model = YOLO("yolo11m.pt")
data = "/DATA/yujiannan/Datasets/process_20251013_20260511_updating/data.yaml"
epochs = 300
imgsz = 1280
batch = 4
name = "18"
cls = 1.0
cos_lr = True
close_mosaic = 60
degrees = 2
translate = 0.05
scale = 0.35
shear = 2
perspective = 0.0001
mosaic = 0.35
erasing = 0.1
```

配置意图：

- 相比默认 YOLO 增强，实验18降低几何扰动和 mosaic 强度，避免老师/学生角色边界被过强增强破坏。
- `cls=1.0` 提高类别损失权重，目标是直接压老师/学生错分。
- `cos_lr=True` 和更长 `close_mosaic=60` 用于让后期收敛更平滑。

后续新实验建议：

- 新实验不要复用 `name="18"`，先改成新的实验号。
- 建议保留实验18作为基线，对照只改一个或两个关键参数。
- 优先尝试：继续围绕 role confusion hard sample 做小幅数据修正；不要为了追求 mAP 单独加大增强。

基于交叉匹配的类别指标：

| 类别 | 指标 | 旧模型 | 实验18 | 变化 |
|---|---|---:|---:|---:|
| teacher | Precision | 0.8844 | 0.9087 | +0.0243 |
| teacher | Recall | 0.9784 | 0.9585 | -0.0199 |
| student | Precision | 0.9700 | 0.9644 | -0.0055 |
| student | Recall | 0.9886 | 0.9842 | -0.0044 |

关键解释：

- `student -> teacher` 明显下降，说明本轮数据和实验18配置对主要痛点有效。
- teacher Precision 变好，是因为预测为 teacher 的数量减少，学生误判老师减少。
- teacher Recall 下降，是因为更多 GT teacher 被预测成 student 或漏检。
- student 漏检和 student 多检都增加，说明实验18对 student 类整体更不稳定。

## 后续实验建议

优先级：

1. 复查 `teacher -> student` 回归样本，尤其是 `image_05380.jpg` 和 `image_05504.jpg`。
2. 复查站立识别退化样本，尤其是 `158169_1`、`166927_6`、`146466_2`、`146349_3`。
3. 继续补充学生视角“学生像老师”的 hard sample，但必须按视频去重，避免同源重复。
4. 老师视角上台展示样本要保留为独立关注集，后续如果要做“学生上台展示”标签，最好单独建立评估子集。
5. 下一轮不要只追 mAP；训练完成后必须同时跑人数统计、站立识别和角色混淆评估。

可尝试方向：

- 在实验18基础上小幅继续调 class/augmentation，不建议一次性大改。
- 针对 `teacher -> student` 回归，补充老师视角中远距离、讲台边缘、老师被遮挡的负例。
- 对学生视角近处大框学生，继续补充 `student` 标注，避免模型把大框/站立/靠近讲台直接当老师。
