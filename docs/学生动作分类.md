# 学生动作分类实验记录

更新日期：2026-06-28

## 当前结论

当前代码默认模型：`student_action_classify_59`

当前训练候选状态：
- `59` 是当前已接入业务代码和 Triton 的模型，但不是稳定终版。
- `58 -> 59` 在业务单测的专注度平均误差上明显改善，`58` 的 focus MAE 约 `0.1493`，`59` 约 `0.0975`。
- `60/61` 是从头训练路线，内部 val top1 低于 `59`，但公平测试集上整体 acc 高于 `59`；其中 `61` 的 focus 指标最好，但站立回答单测更差。
- `62` 是基于 `59` 继续小学习率微调，内部 val top1 很高，但公平集和业务指标没有改善，应视为过拟合/继承旧偏差，不作为候选。

当前主要问题：
- 实际业务视频中仍有明显错误：清晰手机会被判成 `head_down_read_write`，说明 `phone / like_phone / head_down_read_write / head_down_other` 边界还不稳。
- `head_down_other` 容易成为垃圾桶类别，污染 `phone/head_up/head_down_read_write`。
- `stand` 在静态分类上 recall 高，但业务站立回答单测仍不稳，不能只看分类 acc。
- 反复在同一批修正数据上继续微调，容易把模型调向当前错误样本，不适合作为长期主路线。

当前优先级：
1. 先清理当前数据集的大边界噪声，尤其是 `phone/read_write/other/head_up/discuss/blur/pad`。
2. 清理后从 `yolo11s-cls.pt` 从头训练一版完整实验，不再继续从 `59` 反复微调。
3. 训练结果必须同时看内部 val/test、公平测试集、业务单测，不能只按 top1 选模型。

## 类别定义

当前保留 11 类：

| 类别 | 中文 | 业务含义 |
|---|---|---|
| `blur` | 模糊/不可判断 | 接收模糊、遮挡、无法稳定判断的样本，避免污染敏感类别。 |
| `computer` | 玩电脑 | 明确使用电脑。 |
| `discuss` | 交谈 | 辅助监督类别，不直接等价于 head_up。 |
| `head_down_other` | 低头其他 | 低头但不能确认读写、手机、pad、电脑等具体行为。 |
| `head_down_read_write` | 低头读写 | 纸笔、书本、作业等明确读写。 |
| `head_up` | 抬头 | 面向课堂/屏幕/教师，参与抬头率。 |
| `like_phone` | 疑似玩手机 | 类手机姿态或手机证据不足的过渡类别。 |
| `pad` | 玩平板 | 明确使用平板。若拿笔在 iPad 上写且能确认是平板，标 `pad`；只能看到笔、无法确认设备时优先按读写规则处理。 |
| `phone` | 玩手机 | 明确手机。当前最需要防止漏判到 `head_down_read_write`。 |
| `sleep` | 趴桌 | 趴桌/睡觉。 |
| `stand` | 站立 | 站立和站立回答都归为站立。 |

标注规则提醒：
- 不要为了类别均衡强行改类别；先保证边界一致。
- `head_down_other` 只能用于无法确认具体低头行为，不要把清晰手机、清晰读写、清晰 pad 放进去。
- `blur` 只用于图像质量或遮挡导致确实无法判断，不要把困难但可判断的样本放进去。

## 推荐训练方向

下一轮完整实验建议：
- 初始权重：`yolo11s-cls.pt`
- 数据集：清理后的 `/DATA/yujiannan/Datasets/process_20260422_updating_limited`
- 类别：11 类不变
- 预处理：`letterbox`
- imgsz：`224`
- erasing：优先 `0.0` 和 `0.05` 做对照，不预设哪个一定更好
- auto_augment：优先 `None`；RandAugment/AugMix 之前没有稳定业务收益
- 训练方式：从头训练，不继续从 `59` 反复微调

注意：
- `59/62` 这类继续微调路线可能让内部 val top1 虚高，不能作为模型真的变好的证据。
- 新实验必须固定公平测试集，不要把挖掘出来的公平测试样本混入训练。
- 如果新标注数据来自同一批业务视频，业务单测变好也可能带有局部适配，需要额外看未见过视频。

## 为什么这轮不是继续微调

最近实验说明：
- `57/58/59/62` 继承 `39` 后内部 top1 很高，但业务问题没有根治。
- `62` 的 best top1 到 `0.97381`，但公平集和业务指标没有改善，是典型的“内部数据更像旧模型记忆”。
- 每轮只补少量 hard sample 后继续微调，短期可能修复局部 case，但也会引入局部偏差。
- 当前错误集中在类别定义和边界一致性，不是单纯训练不够。

因此下一步应先做数据清理，再从头训练完整实验。
