## 为什么 43 有效

43 的关键不是单纯训练更久，而是几个因素同时对上了业务分布：

1. 继承 v30 last，保留线上已有业务先验。
2. 使用最新 hard sample 数据，尤其补了板书正样本和坐姿负样本。
3. 验证和线上保持纯 `letterbox`，没有回到 center crop，避免坐/站/板书依赖的全身轮廓被裁掉。
4. 训练集使用 `letterbox_crop_style`，只在训练阶段模拟教师检测框松紧变化，让模型不依赖裁剪边界和背景比例。
5. 关闭 RandAugment，只保留较温和的颜色扰动，避免对白板/电子屏/黑板等板书场景造成过强分布扰动。
6. lr0 `5e-5` 从 v30 last 微调，幅度足够吸收新数据，但没有像从头训练那样丢掉旧模型能力。

消融对比支持这个判断：

| 对比 | 变量差异 | 业务变化 | 结论 |
|---|---|---|---|
| 42 -> 43 | 纯 letterbox 改为 `letterbox_crop_style` | 板书 TP `89->90`，TN `35->37`，FP `12->10`，FN `9->8` | crop-style jitter 同时降低 FP/FN，是 43 胜出的核心变量。 |
| 43 -> 44 | 43 去掉 crop-style，44 加 RandAugment | 44 板书 recall 降到 `0.8980`，F1 降到 `0.8934` | RandAugment 没有解决业务问题，反而弱于 43。 |
| 43 -> 46/47 | 降 lr 到 `1e-5` 且短训 | FP 下降，但板书 FN 增到 `16/18` | 过保守会牺牲板书召回，不符合核心目标。 |
| 43 -> 45 | 从 v30 微调改为从头训练 | 静态 acc 和业务板书都更弱 | 当前必须利用 v30 权重，不建议从头训练作为主路线。 |

43 相对 30 的 case 级变化：

- 修复板书 FN：`141754_2`、`149004_1`、`159419_2`。
- 修复板书 FP：`171668_2`、`141318_1`、`141318_2`。
- 新增板书 FP：`149444_6`、`8564_9`。
- 没有新增板书 FN。

43 相对 42 的 case 级变化：

- 修复板书 FN：`202814_1`。
- 修复板书 FP：`141318_1`、`141318_2`。
- 没有新增板书 FP/FN。

这说明 43 不是靠阈值偶然波动，而是 `letterbox_crop_style` 对真实教师框尺度变化更稳。

## 后续建议

不建议在完全相同数据集上继续盲目加实验；但建议沿 43 的思路继续做下一轮专项优化。目标不是换大训练策略，而是用 43 的配置作为基线，补齐当前失败 case。

建议下一轮：

1. 先人工复核 43 的 `10` 个板书 FP 单测标签，尤其 `151757/153577/182162` 这类长时间判 write 的视频。
2. 从 43 的 `8` 个板书 FN 视频挖板书正样本，重点是 `write_duration=0` 的 `167335_1/2`、`148701_1`、`151331_1`。
3. 从 43 的 `10` 个板书 FP 视频挖 hard negative，尤其老师靠近板/屏但没有实际书写的片段。
4. 从 `158253_3`、`171668_2`、`166927_6` 挖坐姿正样本，补坐姿 recall。
5. 用同样的 43 训练配置开下一轮实验：v30 last 初始化、`letterbox_crop_style`、lr0 `5e-5`、无 RandAugment。
6. 如果需要排查中间 epoch，再临时加 `save_period=1` 保留 checkpoint；默认脚本保持和 43 一致。
7. 若仍有接近阈值的板书 FN/FP，再单独做 `write_duration` 和 `write_score >= 0.9` 阈值扫描。

不建议优先做：

- 从头训练：45 已证明明显弱。
- 继续降低 lr 做保守微调：46/47 板书 recall 下降。
- 只加 RandAugment：44 没有收益。
- 粗暴类别均衡或下采样 stand/book：会破坏坐姿和板书负样本分布。

1. 用 Triton letterbox 复核 43 ONNX 的静态 test 与业务单测。
2. 确认 Triton config 的 batch 维度与 `best.onnx` 一致。
