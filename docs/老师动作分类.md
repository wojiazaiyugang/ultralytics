## 训练方式说明

当前推荐的线上一致预处理是 `letterbox`，不要回退到默认 center crop。

已有自定义 trainer：
- `LetterBoxClassificationTrainer`：训练/验证都先补正方形再 resize，和线上 `preprocess_mode="letterbox"` 对齐。
- `CropStyleClassificationTrainer`：只在训练集模拟紧框/松框，但验证集回到 Ultralytics 默认 center crop，不适合直接作为线上 letterbox 模型的最终方案。
- `LetterBoxCropStyleClassificationTrainer`：训练集先做 crop-style jitter，再 letterbox；验证集保持纯 letterbox。这个是为了验证检测框松紧扰动是否能提升业务泛化。

注意：
- `args.yaml` 不会记录自定义 `trainer=...`，所以 38/39 的 args 看起来几乎一样，但实际 trainer 不同。
- `auto_augment=randaugment` 时，当前 `letterbox_classification.py` 不会再走 HSV ColorJitter 分支；关闭 `auto_augment` 后才会使用 `hsv_h/s/v` 对应的颜色扰动。

## 当前推荐训练策略

优先目标：
1. 坐姿单测不低于 v30。
2. 板书单测优于 v30。
3. 不以 val top1 单独决定上线模型。

当前最值得做的工作：
- 从板书 FN 视频定向挖老师框 hard positive：`167335_1`、`167335_2`、`141754_2`、`178803_7`、`140800_4`、`148701_1`、`140558_1`、`140558_2`、`151331_1`。
- 用已有事件缓存做 `has_write` 阈值扫描，验证降低 `write_score` 阈值、降低高置信时长或降低总 write 时长是否会带来不可接受的 FP。

推荐选择规则：
- 当前不再优先 38：它静态 test set 好，但业务坐姿漏判多。
- 39 是当前新实验里坐姿相对最好的微调模型，但仍未达到 v30。
- 40 证明从头训练路线不优先；除非换更强数据策略，否则不继续投入。
- 41 保住了坐姿 precision，但没有补上板书 recall；也不应上线。
- 如果继续优化坐姿 recall，应补 `171668_2`、`158253_3`、`166927_6` 这类坐姿正样本；如果只要求坐姿 precision，当前 38/41 已经满足 FP=0。
- 如果板书仍不足：继续补白板、电子屏、电子笔、手写但非黑板场景，并重点复核业务单测中的 FP/FN。

下一轮训练前置条件：
- 先补板书 FN hard positive，再训练；否则继续训练只会复现 38/39/41 的问题。
- 训练后必须先跑板书 FN 靶向集，靶向 recall 明显提升后再跑全量 `tests/test_teacher_has_write.py`。

## 后续实验禁忌

- 不要直接用 `PREPROCESS="crop_style"` 作为最终模型训练方案，因为它的验证集不是线上 letterbox。
- 不要只看 `metrics/accuracy_top1`，34 已经证明 val top1 高不代表业务规则好。
- 不要优先扩大实验矩阵；每次只改一个关键变量，保证能解释结果。
- 不要用学生动作分类或 PPT 分类结论推断老师动作分类。
