## 为什么 49 有效

49 的关键不是“多训练几轮”，而是继承了 43 已经验证有效的业务边界，再用 2026-06-28 最新 hard sample 做小步微调：

1. 43 已经证明 `letterbox_crop_style` 比纯 letterbox 更贴近真实教师检测框抖动。
2. 49 从 `43/weights/best.pt` 初始化，保留了 crop-style 学到的坐/站/板书边界。
3. 新数据补入了白板、电子屏、电子笔板书样本，以及坐姿 hard sample。
4. lr0 降到 `2e-5`，只做小幅吸收新数据，没有像从头训练那样丢掉线上 v30/43 的先验。
5. 验证和线上仍保持纯 `letterbox`，训练阶段才做 crop-style jitter。
6. 继续关闭 RandAugment，只保留温和颜色扰动，避免对白板/电子屏/黑板场景做过强破坏。

消融对比支持这个判断：

| 对比 | 变量差异 | 业务变化 | 结论 |
|---|---|---|---|
| 42 -> 43 | 纯 letterbox 改为 `letterbox_crop_style` | 板书 TP `89->90`，TN `35->37`，FP `12->10`，FN `9->8` | crop-style jitter 是 43 胜出的核心变量。 |
| 43 -> 49 | 43 best 上用新数据小学习率微调 | 坐姿 FN `15->3`，板书 FP `10->7`，板书 FN 保持 `8` | 新增数据主要修复坐姿漏判和板书误报，没有牺牲板书召回。 |
| 49 -> 51 | 49 best 继续二次小学习率微调 | 板书 case 级结果不变，坐姿 FN `3->10` | 无新增数据时继续叠微调没有收益。 |
| 48 -> 49 | 同一新数据，48 从 v30 last，49 从 43 best | 48 静态/业务均弱于 49 | 43 的 crop-style 先验必须保留。 |
| 49 -> 50/52 | 49 微调，50/52 从 `yolo11s-cls.pt` 训练 | 50/52 静态 acc 和 write recall 明显更低 | 当前数据量不支持从头训练作为主路线。 |

49 相对 43 的 case 级变化：

- 坐姿 FN 从 `15` 降到 `3`，修复了 `171668_2`、`166927_6` 以及部分 `158253_3`。
- 板书 FP 从 `10` 降到 `7`，修复了 `182162_3`、`182162_4`、`8564_9`。
- 板书 TP/FN 不变，没有新增板书漏报。

这说明 49 的收益主要来自新增定向数据和保守微调，不是随机阈值波动。

3. 从 49 的 `7` 个板书 FP 视频挖 hard negative，重点是老师靠近板/屏但没有实际书写的片段。
4. 从 `158253_3` 补少量坐姿正样本，目标是消掉最后 3 个坐姿 FN。
5. 如果只追加少量针对性数据，优先从 `49/weights/best.pt` 初始化，lr0 可先用 `1e-5` 到 `2e-5`，epochs `10-20`。
6. 同时保留一组从 `43/weights/best.pt` 初始化的对照，避免 49 在小数据上继续偏保守。
7. 标签复核完成后，再单独做 `write_duration` 和 `write_score >= 0.9` 阈值扫描；阈值扫描不能替代数据修正。

不建议优先做：

- 从头训练：50/52 已证明明显弱于微调。
- 无新增数据继续微调：51 没有收益，且坐姿变弱。
- 只加 RandAugment：44 没有收益。
- 粗暴类别均衡或下采样 stand/book：会破坏坐姿和板书负样本分布。
